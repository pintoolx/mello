# Mello design context

- Audience: Taiwanese finance, risk, procurement, and engineering teams evaluating an agent purchase-control product in a business setting.
- Use case: two fully separate apps. The primary website is the persistent procurement workspace Canfly operates and records for the hackathon. A separately runnable documentation site replaces the marketing homepage. No cross-links, shared navigation, marketing CTA, or embedded videos between these apps.
- Brand personality: documentary, procedural, trustworthy. Reference enterprise forms, internal-control software, stamped records, and legacy ERP information density without becoming unusable.
- Brand: enterprise operations system, not a retail crypto product or neon Web3 dashboard. Figma green remains a restrained status accent alongside navy ink, warm paper, gray table headers, and hairline rules.
- Typography: restrained Noto Sans TC for the workspace and reading-focused documentation; Roboto Mono only for IDs, times, and machine records. No oversized marketing headings.
- Signature: purchase intent becomes a numbered document whose policy, payment, service, invoice, and reconciliation records can be audited in one view.
- UI rules: square enterprise panels, compact controls, real tables, document metadata, restrained type sizes, no gradients, no glassmorphism, no ornamental crypto motifs, no oversized demo-state typography.
- Copy: concrete, audit-oriented, concise. Always label simulated settlement and test invoices clearly.
- Information architecture: request list → create request → case detail. Payments, invoices, policy, and audit are genuine routes, not anchors in a demonstration. Case tabs organize evidence; no numbered stage navigation or giant ALLOW/MATCHED stamps.
- Interaction: save a request before an explicit submission; fetch persisted API state, never animate a timer into a fake settlement. Keep errors, empty states, refresh, and recovery actions usable. No reset-demo, test-injection, fake freeze, or unsupported duplicate-purchase controls.
